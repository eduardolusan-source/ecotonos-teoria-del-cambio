# Teoría del cambio · Ecotonos del valle de Concá

Página estática del Laboratorio de Desarrollo Rural (UAQ Campus Concá) para que el equipo recorra la lógica del proyecto antes de la reunión.

- `index.html`: la página. La constante `SHEET_API` del script apunta a la aplicación web de Google Apps Script que guarda y devuelve las respuestas del equipo.
- `img/`: fotografías del proyecto (EURC, FONFIVE FI-2024-18) y de los talleres.
- `apps-script.gs`: backend para Google Sheets; se pega en Extensiones → Apps Script y se despliega como aplicación web.
